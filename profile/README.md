## 👋 Welcome to ESP-Mosaico

A desk companion that listens. A camera you can program. A game that spans two screens. Your next creation can start here.

**ESP-Mosaico is Espressif's modular development platform for creating hardware with AI.** This organization brings together device firmware, an Agent development workspace, board support, and tools to help you describe an idea, assemble the hardware, build an application, and keep improving it on a real device.

## 🚀 Choose your starting point

| What would you like to do? | Start here |
| --- | --- |
| **Bring your board to life** | Follow the [getting started guide](https://mosaico.espressif.com/guide/), then try conversations, interfaces, and skills with [ChatCoding](https://mosaico.espressif.com/guide/chat-coding/). |
| **Try someone else's idea** | Visit [Ideas Center](https://mosaico-ideas.espressif.com/) to discover apps for your device and modules. |
| **Build an app with an Agent** | Open [ESP-Mosaico Vibe](https://github.com/esp-mosaico/esp-mosaico-vibe), create a project, validate it in the simulator, and deploy it to your board. |
| **Start with the hardware** | Explore the [BSP examples](https://github.com/esp-mosaico/esp-mosaico-bsp/tree/master/examples) for displays, audio, sensors, expansion modules, and multi-device interaction. |

## 🌐 Open-source projects that work together

From the Agent on your board to the workspace on your computer, these projects connect application creation, hardware support, and device maintenance.

| Project | What you can do here |
| --- | --- |
| [**ESP-Mosaico Vibe**](https://github.com/esp-mosaico/esp-mosaico-vibe) | **Build apps with an Agent.** A workspace with project creation, Agent guidance, and workflows for previewing, building, and working with devices. |
| [**ESP-Mosaico Claw**](https://github.com/esp-mosaico/esp-mosaico-claw) | **Customize the device Agent and factory firmware.** Built on ESP-Claw, with conversations, memory, skills, Lua extensions, MCP, and touchscreen apps. |
| [**ESP-Mosaico Matter**](https://github.com/esp-mosaico/esp-mosaico-matter) | **Connect and control your smart home.** Matter hub and bridge applications with device commissioning, control, automation, web and on-device UIs, and AI agent integration through ESP-Claw and MCP/Skills. |
| [**ESP-Mosaico BSP**](https://github.com/esp-mosaico/esp-mosaico-bsp) | **Connect hardware and build from examples.** Board interfaces, module management, peripheral drivers, and multi-device communication components. |
| [**ESP-Mosaico Utils**](https://github.com/esp-mosaico/esp-mosaico-utils) | **Improve development, debugging, and maintenance.** ESP-Iris, the CLI, Web Workbench, Vibe Mode firmware, and shared application resources. |

## 🤝 Bring your piece of the mosaic

Join in with a project, a question, or an improvement:

- **Create something new:** start from the [Vibe workspace](https://github.com/esp-mosaico/esp-mosaico-vibe) or a [BSP example](https://github.com/esp-mosaico/esp-mosaico-bsp/tree/master/examples) and turn your idea into a working app.
- **Help the next developer:** contribute documentation, reproduction steps, or module experience through an issue or pull request in the relevant repository.
- **Improve the foundations:** work on the [Claw device experience](https://github.com/esp-mosaico/esp-mosaico-claw), [BSP hardware support](https://github.com/esp-mosaico/esp-mosaico-bsp), or [Utils development tools](https://github.com/esp-mosaico/esp-mosaico-utils).
